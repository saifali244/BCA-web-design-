HTML Character Entity Challenge

HTML entities display special characters that may otherwise be interpreted as HTML markup.

CharacterEntity ReferenceMeaning / Use
<&lt;Less-than sign / opening angle bracket
>&gt;Greater-than sign / closing angle bracket
&&amp;Ampersand
©&copy;Copyright symbol
®&reg;Registered trademark
"&quot;Quotation mark
'&apos;Apostrophe
 &nbsp;Non-breaking space
×&times;Multiplication sign
÷&divide;Division sign
±&plusmn;Plus-or-minus sign
≤&le;Less than or equal to
≥&ge;Greater than or equal to

Example

To display the tag <p>Hello</p> as text, write &lt;p&gt;Hello&lt;/p&gt; in the HTML source.

Mathematical example: 5 × 4 = 20; 10 ÷ 2 = 5; x ≤ 10.
